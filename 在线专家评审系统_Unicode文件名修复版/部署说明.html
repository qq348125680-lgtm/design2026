在线专家评审系统：5分钟部署说明

这套系统本身不需要购买服务器。免费使用 Supabase 保存作品和评分，再把网页免费放到 Cloudflare Pages / Netlify / GitHub Pages 即可。

第一步：建免费 Supabase 项目

  1. 打开 supabase.com，注册并新建 Project。
  2. 进入 SQL Editor，新建 Query。
  3. 打开本压缩包中的 supabase_setup.sql，全选复制进去，点击 Run。
    本修正版已处理 Supabase 的 pgcrypto/crypt 架构问题。
  4. 默认管理员口令是 123456。正式比赛前请按 SQL 文件最后一行示例改掉。

第二步：填两个参数

  1. Supabase 左侧 Project Settings → API。
  2. 复制 Project URL 和 anon public key。
  3. 用记事本打开 config.js，替换 YOUR_PROJECT 和 YOUR_ANON_KEY。

第三步：先在本机测试

双击 index.html，进入管理后台。管理员口令 123456。先添加1个专家，再上传1个 ZIP 测试。

第四步：免费发布到公网

最省事：使用 Cloudflare Pages 的 Direct Upload，或者 Netlify Drop，把整个文件夹拖进去即可。发布后会得到一个 https://xxxx.pages.dev 或 netlify.app 的网址。

把 judge.html 的网址生成二维码发给专家，例如：

https://你的网址/judge.html

比赛当天专家怎么用

扫码 → 输入邀请码 → 左边选 A01/A02 → 右边直接看图片/PDF → 填分 → 保存 → 下一件。

注意

  • 建议把超大视频、PSD、源工程文件仍作为下载附件；评审用 JPG/PDF 最流畅。
  • 说明文档中的 DOCX、PPTX、TXT、MD 已支持浏览器内直接查看文字内容，无需专家先下载。
  • 本修正版已处理中文文件名导致 Supabase Storage 报 Invalid key 的问题：云端对象名自动改成英文安全路径，但专家端仍显示原中文文件名。
  • 免费额度适合几十件到上百件普通平面作品。若每个 ZIP 都几百 MB，免费存储可能不够。
  • 比赛结束后从后台导出成绩，再删除 Supabase 项目即可。
  • 本版新增：图片点击全屏放大；PDF页内预览；Word/PPT/Excel通过 Office Web Viewer 尽量保持原始排版在线查看；TXT/MD/CSV/JSON 自动整理为可读页面。
